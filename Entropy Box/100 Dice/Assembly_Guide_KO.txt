Entropy Box 100 — V3 형상의 100개 주사위 모델

완성 외형: 108 x 108 x 19mm
투명판: 100 x 100 x 2mm (별도 준비, 3D 출력 부품 아님)
주사위: 한 변 5mm, 100개 / 배열 10 x 10

기존 25개 V3에서 유지한 부분
수납칸 아래쪽은 6 x 6mm, 입구는 8 x 8mm이며 칸 간격은 8.8mm입니다.
칸 바닥 높이 1.4mm, 직선 지지벽 높이 4mm, 경사 유도면 높이 1mm입니다.
전체 칸 깊이는 5mm이므로 5mm 주사위가 정상 안착하면 윗면이 칸막이와
같은 높이가 됩니다. 칸 위 공용 굴림 공간의 높이는 9mm입니다.
외부에서는 걸쇠 슬롯이 보이지 않는 내부 탄성 걸쇠 구조를 유지합니다.

100mm 투명판에 맞춘 부분
본체와 뚜껑의 외형을 108 x 108mm로 확장했습니다.
투명판 삽입 자리: 100.6 x 100.6mm (명목상 판의 한쪽 여유 0.3mm)
투명판 아래 받침: 한쪽 6mm / 위쪽 높이 여유: 0.2mm
투시창과 굴림 공간의 평면 크기: 88 x 88mm
본체-뚜껑의 명목상 옆 간극은 한쪽 0.05mm입니다.
숨은 걸쇠는 각 면에 4개씩, 총 16개입니다.
걸쇠의 잎 두께 1mm, 유연 구간 길이 8.2mm, 맞물림 0.5mm는 기존 V3와 같습니다.
압착 가이드 돌기는 총 20개이며 끝단의 명목상 간섭은 0.05mm입니다.
100개용 본체와 뚜껑을 함께 사용하십시오. 기존 25개용 뚜껑은 크기가 달라
호환되지 않습니다.

출력 파일
Entropy_Box_100_V3_Base.stl / .step: 본체
Entropy_Box_100_V3_Lid.stl / .step: 출력 방향을 적용한 뚜껑
두 파일 모두 바닥 z=0입니다. 제공한 STL 방향으로 출력하십시오.
Entropy_Box_100_V3_Print_Layout.stl / .step: 두 부품을 나란히 놓은 선택 배치
선택 배치의 크기는 226 x 108mm이므로 가장자리 여유까지 고려해야 합니다.
220mm 출력판에서는 본체와 뚜껑 개별 파일을 따로 배치해 출력하십시오.
개별 파일과 선택 배치를 동시에 불러오면 부품이 중복됩니다.

Reference 파일은 조립 검토용이며 출력 대상이 아닙니다.
ClearPanel_100x100x2_REFERENCE: 실물 투명판 대신 표시한 참고 형상
Dice_100_REFERENCE: 5mm 정육면체 100개의 안착 상태 참고 형상
Entropy_Box_100_V3_Assembly_REFERENCE.step: 닫힌 상태의 전체 조립
미리보기의 주사위 눈금은 표시용이며 실제 출력 부품 형상에 가공하지 않았습니다.

조립
주사위 100개를 본체에 넣고, 100 x 100 x 2mm 투명판을 받침에 올립니다.
판이 평평하게 내려앉았는지 확인한 뒤 뚜껑을 수평으로 맞춰 네 면을
고르게 눌러 체결하십시오. 내부 걸쇠가 있어 최종 체결 전에 주사위 개수와
투명판의 보호필름 제거 및 상태를 확인하는 것이 좋습니다.

출력과 검증 범위
PLA와 기존 V3 출력 설정을 기준으로 설계했습니다. 걸쇠의 작은 단차 때문에
기존처럼 0.1mm 고정 레이어를 시작 조건으로 사용할 수 있습니다.
이번 100개 모델에서 실제 슬라이싱이나 실물 출력 시험은 수행하지 않았습니다.
작은 25개 모델보다 판이 넓어 출력 수축과 휨에 따른 체결 차이를 확인해야 합니다.
CAD 및 STL 검사 결과는 Verification에 포함된 보고서를 확인하십시오.
정육면체 기준으로 안착과 회전 공간을 검토했습니다. 실제 주사위의 치수,
모서리 모양, PLA 출력 오차, 흔들었을 때 100개가 모두 정렬되는 성능 및
뚜껑을 분리하는 데 필요한 힘은 출력품으로 확인해야 합니다.
